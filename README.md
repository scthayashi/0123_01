# 政令指定都市プレゼンテーション

日本全国の政令指定都市（20市）の魅力を紹介するPowerPointプレゼンテーション資料を自動生成するプロジェクトです。

## 概要

このプロジェクトは、日本の政令指定都市すべてについて、以下の情報を含むプレゼンテーション資料を生成します：

- 各都市の基本情報（人口、地域）
- 推奨度（★評価）
- 主な特徴・魅力ポイント
- 生活コスト
- 気候情報
- 都市の魅力ポイント

## セットアップ

### 必要要件
- Python 3.7以上

### インストール

```bash
# 依存ライブラリのインストール
pip install -r requirements.txt
```

## 使い方

```bash
# プレゼンテーション資料の生成
cd src
python generate_presentation.py
```

実行すると、`output/政令指定都市の魅力.pptx` が生成されます。

## 生成されるスライド

1. **タイトルスライド** - プレゼンテーションのタイトル
2. **概要スライド** - 政令指定都市の説明
3. **各都市スライド（20枚）** - 各都市の詳細情報
4. **比較スライド** - 推奨度別一覧
5. **結論スライド** - 都市選びのポイント

合計：**24スライド**

## 推奨度について

推奨度は以下の基準で評価しています：

- **★★★★★**（最高評価）: 大都市で利便性・文化・経済力が高い
- **★★★★☆**（高評価）: 地域の中核都市で住みやすさが高い
- **★★★☆☆**（標準評価）: バランスの取れた生活環境

※推奨度は都市の規模、利便性、文化、自然環境、経済力などを総合的に評価したものです。

## カスタマイズ

`src/cities_data.py` を編集することで、都市データを追加・変更できます。
